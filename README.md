# Resume

An elegant resume using LaTeX.

## Usage

The repo contains the Dev Container configuration with all required dependencies for compilation. It uses a Makefile to build the LaTeX project. Below are the commands and their usage:

- `make clean` - clean the build directory and remove any generated PDF files
- `make build` - build the resume LaTeX project and create the PDF file in the build directory
- `make archive` - copy the generated PDF to the archive directory with a date-stamped filename (e.g., `umang_YYYY-MM-DD.pdf`)
